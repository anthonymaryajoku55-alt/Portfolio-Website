This portfolio was created to provide a simple, modern, and responsive way to introduce myself and display the projects I have worked on.

The website includes sections such as:

* **About Me** – Information about me and my interests
* **Skills** – Technologies and skills I am learning
* **Projects** – Some of the projects I have created
